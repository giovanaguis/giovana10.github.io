# MeuSite

Site escolar criado com HTML, CSS e JavaScript.

## Páginas
- Início: `index.html`
- Cadastro: `cadastro.html`
- Contato: `contato.html`
- História: `historia.html`
- Sobre: `sobre.html`

## Funcionalidades
Layout responsivo, alternância de modo escuro, validação dos formulários e mapa incorporado.

**Atenção:** os formulários são demonstrativos e não salvam contas ou enviam mensagens. Os dados de contato são exemplos.

## Publicação
Para ativar a hospedagem, abra **Settings → Pages → Build and deployment → Deploy from a branch**, escolha **main** e **/(root)** e clique em **Save**.
